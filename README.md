# Homebrew tap

Apps by [MelvinSDRS](https://github.com/MelvinSDRS) for [Homebrew](https://brew.sh).

```sh
brew install --cask melvinsdrs/tap/swiftr
```

| Cask | What it is |
| --- | --- |
| `swiftr` | [Swiftr](https://github.com/MelvinSDRS/swiftr): your terminals and coding agents, on every machine, in one Mac app |

Each Swiftr release updates its cask here.
